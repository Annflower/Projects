# game_snake

Классическая игра «Змейка» на Python с использованием Pygame.

## Управление

| Клавиша    | Действие        |
| ---------- | --------------- |
| ↑ / ↓ / ← / → | Направление движения |
| Пробел     | Начать заново после проигрыша |
| Esc        | Выйти после проигрыша |

## Правила

- Змейка движется по полю и растёт, съедая красную еду.
- За каждую съеденную еду начисляется 1 очко.
- Игра заканчивается при столкновении со стеной или с собственным телом.

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите игру:

```bash
python snake.py
```

## Требования

- Python 3.9+
- Pygame
