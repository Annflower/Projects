# ping-pong

Классический «Пинг-понг» на Python с использованием Pygame. Игра идёт до 10 очков.

## Управление

| Клавиша              | Игрок  | Действие        |
| -------------------- | ------ | --------------- |
| W / S                | Левый  | Вверх / вниз    |
| ↑ / ↓                | Правый | Вверх / вниз    |
| Пробел               | —      | Начать заново после победы |

## Правила

- Игроки управляют ракетками и отбивают мяч.
- Мяч ускоряется после каждого забитого гола (до предела).
- Тот, кто первым набирает 10 очков, побеждает.

## Запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите игру:

```bash
python ping_pong.py
```

## Требования

- Python 3.9+
- Pygame
