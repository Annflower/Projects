
# Шифры

Реализация шифра вертикальной перестановки и определение языка текста на Python.

## Описание

Проект содержит:

- **Шифр вертикальной перестановки** — шифрование и дешифрование текста
- **Brute-force** — автоматический подбор ключа
- **Определение языка** — русский / английский
- **Unit-тесты** — проверка корректности кода
- **Задача** — расшифровка текста «Приключения Тома Сойера»

## Структура проекта

| Файл               | Описание                                                         |
| ---------------------- | ------------------------------------------------------------------------ |
| `transposition.py`   | Шифр вертикальной перестановки               |
| `language_detect.py` | Определение языка текста                           |
| `test_ciphers.py`    | Unit-тесты (unittest)                                               |
| `solve_tom.py`       | Решение задачи: поиск ключа для`tom_enc.txt` |
| `tom_open.txt`       | Открытый текст (Том Сойер)                          |
| `tom_enc.txt`        | Зашифрованный текст                                    |
| `dictionary.txt`     | Английский словарь (опционально)             |
| `russian.txt`        | Русский словарь (опционально)                   |

## Функции

### `transposition.py`

| Функция                       | Описание                    |
| ------------------------------------ | ----------------------------------- |
| `transposition_encrypt(text, key)` | Зашифровать текст   |
| `transposition_decrypt(text, key)` | Расшифровать текст |
| `brute_force(ciphertext)`          | Подобрать ключ         |

### `language_detect.py`

| Функция       | Описание                                         |
| -------------------- | -------------------------------------------------------- |
| `is_russian(text)` | Проверить, русский ли текст       |
| `is_english(text)` | Проверить, английский ли текст |
