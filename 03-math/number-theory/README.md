
# Теория чисел

Модуль с алгоритмами теории чисел на Python.

## Описание

Реализация классических алгоритмов теории чисел:

- НОД (4 метода)
- Расширенный алгоритм Евклида
- Факторизация
- Функция Эйлера
- Обратный элемент по модулю
- Системы вычетов

## Функции

| Функция                         | Описание                                                                  |
| -------------------------------------- | --------------------------------------------------------------------------------- |
| `mod(a, m)`                          | Остаток от деления`a` на `m`                                |
| `gcd_mr(a, b)`                       | НОД методом вычитания (рекурсия)                       |
| `gcd_m(a, b)`                        | НОД методом вычитания (цикл)                               |
| `gcd_er(a, b)`                       | НОД алгоритмом Евклида (рекурсия)                     |
| `gcd_e(a, b)`                        | НОД алгоритмом Евклида (цикл)                             |
| `is_coprime_pairs(lst)`              | Проверка взаимной простоты                                |
| `least_residue_system(m)`            | Система наименьших неотрицательных вычетов |
| `absolutely_least_residue_system(m)` | Система абсолютно наименьших вычетов             |
| `reduced_residue_system(m)`          | Приведенная система вычетов                              |
| `gcd_ext_r(a, b)`                    | Расширенный алгоритм Евклида (рекурсия)         |
| `gcd_ext(a, b)`                      | Расширенный алгоритм Евклида (цикл)                 |
| `factorization(n)`                   | Факторизация числа                                               |
| `phi_function_r(n)`                  | Функция Эйлера (через вычеты)                             |
| `phi_function_t(n)`                  | Функция Эйлера (через факторизацию)                 |
| `inverse(a, m)`                      | Обратный элемент по модулю                                 |
